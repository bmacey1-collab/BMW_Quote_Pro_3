Changelog

3.0.0 Alpha 5

  • Fixed the startup error that left the scenario workspace empty.
  • Restored default scenarios and Add Scenario controls.
  • Restored Cash Purchase and One-Pay Lease templates.
  • Removed the legacy calculator and legacy results completely.

3.0.0 Alpha 4

  • Restored automatic lease residual adjustments by included annual mileage.
  • Added in-service and custom-mile residual deductions.
  • Added individual deal incentives by quote type.
  • Added Cash and One-Pay Lease scenario templates.
  • Added monthly Program Center with saved history and copy-prior workflow.
  • Added program loading into scenario fields.

3.0.0 Alpha 3

  • Added Dealer Settings and default fees.
  • Changed Deal Builder pricing from Selling Price to Dealer Discount.
  • Added calculated adjusted selling price.
  • Added fee treatment: upfront, capitalized, or not applicable.
  • Added real customer presentation from selected scenarios.
  • Added optional rate, residual, balloon, and due-upfront detail display.
  • Added printable customer quote and manager worksheet.

3.0.0 Alpha 2

  • Added working Lease, Finance, Cash, and BMW Select scenario calculations.
  • Added rename, duplicate, delete, edit, and present-any-three controls.
  • Added required-field validation.
  • Added working Roll Payment calculations for selling price, cash, and trade allowance.
  • Added first/last name, co-buyer, salesperson, vehicle, trade, ACV, cost, notes, and signature settings.
  • Added lease trade-equity allocation.

3.0.0 Alpha 1

  • Dashboard is now the landing page.
  • Recent Quotes remain on the dashboard.
  • Added colored flexible-scenario previews.
  • Added Program Center and Manager Worksheet foundations.
  • Version 2.4.1 remains separate for production.

v2.4.1

  • Restored the Email Quote button on the Results screen.
  • Added a mobile Email shortcut.
  • Email Quote now pre-fills the customer, subject, quote reference, and message template.

v2.4.0

  • Added responsive mobile layouts and touch-friendly controls.
  • Added installable Progressive Web App support.
  • Added swipeable result cards on phones.
  • Added a mobile bottom navigation bar.
  • Removed the unreliable custom PDF button; use Print Results → Save as PDF.

v2.3.3

  • Fixed Create PDF so the quote always fits on one landscape Letter page.

v2.3.2

  • Restored landscape full-page quote printing.
  • Added Create PDF download.
  • Corrected lease upfront tax to exclude trade equity.

v2.3.1

  • Fixed Save Quote and Email buttons.
  • Added Open Gmail browser option.
  • Added clearer runtime error notifications.

v2.2.2

  • Added Cash Purchase inside Finance.
  • Renamed cards to Lease, Finance, and BMW Select.
  • Added About & Backup diagnostics.
  • Added quote export and settings backup.

v2.2.1

  • Persistent login and automatic reconnection.
  • Collapsed connection settings after sign-in.
  • Save/update confirmations.
  • One-page printing and private notes excluded.
