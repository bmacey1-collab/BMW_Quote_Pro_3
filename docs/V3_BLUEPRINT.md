# BMW Quote Pro 3.0 Blueprint

Alpha 1 build date: 2026-07-24

## Locked in

- Dashboard landing page with Recent Quotes.
- Lease blue, Finance green, Cash charcoal, BMW Select orange.
- Flexible scenarios; build up to six and present any three.
- Payment Roller.
- Required-field validation with intentional zero accepted.
- Program archive with prior months retained.
- Manager worksheet with cost, ACV, gross, reserve and 70% reserve share.
- No total interest on customer quotes.
- Archive instead of delete; backups and audit trail.
- Version 2.4.1 remains the production app.
